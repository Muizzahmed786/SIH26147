# MVP Scope

- Required Input: WAV, IQ, SigMF.
- Signal Visualization: Waveform, FFT/PSD, Waterfall, Constellation.
- Signal Characterization: Sample rate, BW, SNR, etc.
- Modulation Classification: BPSK, QPSK, 8PSK, 2FSK, 4FSK, GFSK, 16QAM.
- Demodulation: FSK, PSK, QAM.
- Bit Analysis: Bit-stream extraction, correlation.
- Recovery: Block de-interleaving, Viterbi, Reed-Solomon.
