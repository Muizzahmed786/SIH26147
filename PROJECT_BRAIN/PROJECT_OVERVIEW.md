# Project Overview

## Problem
Automated analysis of .IQ and .wav files with parameter extraction.

## Proposed Solution
An evidence-driven RF signal analysis workstation that converts .IQ / .WAV recordings into visual signal intelligence, modulation hypotheses, recovered bit streams, and validated decoding results using a hybrid DSP + ML + configurable recovery pipeline.

## Core Philosophy
Observe -> Measure -> Hypothesize -> Process -> Validate -> Report

System distinguishes between Measurements, Estimates, ML classifications, Decoder hypotheses, and Validated results.
